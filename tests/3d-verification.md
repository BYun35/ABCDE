# 第一關 3D 自由走動驗證

日期：2026-11-03

## 已確認的工作範圍

使用者選擇將第一關改為自由走動 3D：鍵盤移動、滑鼠轉向。沿用已檢查第一關的密碼與道具流程；不修改根目錄 BRIEF.md、VERIFY.md 或 PLANS.md。既有第一關驗證紀錄見 level-one-verification.md。

## 操作方式

1. 以瀏覽器開啟 game/index.html，按「進入病房」。
2. WASD／方向鍵移動，按住場景拖曳轉向。也可按「鎖定滑鼠」，Esc 釋放；瀏覽器拒絕鎖定時仍可拖曳。
3. 靠近立體物件點擊，或對準中心準星後按 E；場景互動距離限制為 2.4 單位。
4. 可使用畫面下方的移動與轉向按鈕。旁邊的線索筆記保留既有閱讀、收集、排序、密碼與道具操作，作為輔助操作，不強制只能透過場景完成。
5. 按鈕和輸入欄取得焦點時，不讓鍵盤移動影響輸入。視窗失焦時清除移動狀態。

## 瀏覽器實際操作結果

以本機靜態預覽使用一般操作，未修改遊戲狀態：

- WebGL 病房正常顯示，包含床、人物、床頭櫃、三瓶藥物、日曆、塗鴉、時鐘、垃圾桶及門禁感應器。
- 按 W 後玩家位置從入口 z=4.400 前進至約 z=1.966。
- 滑鼠拖曳能轉動視角。
- 點擊立體病床能顯示警告線索。
- 點擊地面病歷碎片能加入背包；修正紙上線條擋住點擊的問題。
- 走向病床時位置停於床邊，沒有穿入床體。
- 預覽環境拒絕滑鼠鎖定時顯示拖曳轉向提示。此環境未能驗證成功鎖定滑鼠後的轉向，拖曳模式已驗證。
- 使用筆記區補收其餘碎片、讀病歷、排序、連續輸入三次錯誤後改輸入 317、取得工具、拆瓶取卡與刷卡，能顯示第一關結尾；3D 場景同步完成狀態。

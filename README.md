## 怎麼玩

### 開始遊戲

用瀏覽器開啟 `game/index.html`，按下「進入病房」開始探索。

### 基本操作

- 使用 `WASD`（`W`、`A`、`S`、`D`）移動。
- 使用滑鼠轉動視角；按 `E` 與附近物件互動。
- 按 `Esc` 釋放滑鼠，或使用畫面上的方向按鈕移動。
- 使用「互動」按鈕操作目前面前的物件。
- 使用「線索／背包」查看已發現的線索與道具。
- 手電筒亮度可用下方按鈕調整。

### 第一關：病房——消失的病歷

1. 探索病房，查看警告紙條、藥瓶、日曆、牆面塗鴉與病歷碎片。
2. 撿起床墊下、床頭櫃後方和垃圾桶旁的三片病歷碎片。
3. 依照「午夜前 → 午夜後 → 清晨」排列藥瓶：`A → B → C`。
4. 將密碼 `317` 輸入床頭櫃密碼鎖，取得抽屜裡的工具。
5. 用工具拆開藥瓶 C 的瓶底，取得門禁卡。
6. 在病房門的感應器刷卡，前往護理站。

### 第二關：護理站——被篡改的記錄

1. 比對值班表與三份病歷，找出簽署人不符合值班時間的病歷 B。
2. 檢查病歷 B 背面的錄音帶並播放，取得實驗啟動日期。
3. 輸入日期密碼 `0217`，開啟桌子下方的隱藏抽屜。
4. 閱讀實驗檔案，取得地下研究區電梯卡。
5. 使用電梯卡前往地下研究區。

### 第三關：手術室——不屬於自己的記憶

1. 進入地下手術室後，調查四張照片與手術紀錄。
2. 依照事件發生順序排列照片：簽署同意書 → 進入醫院 → 接受記憶移植 → 記憶清除完成。
3. 依照片背面的數字輸入控制台密碼 `4132`，開啟抽屜並取得監視器遙控器。
4. 用遙控器播放監視器的三段實驗影片，了解 NO.01 與 NO.02 的身分及實驗經過。
5. 閱讀研究員備忘錄，取得地下研究區通行證。
6. 到手術室出口使用通行證刷卡，解鎖緊急出口並離開醫院。

完成第三關後會播放 NO.01 留下的最後訊息，並進入結局「重新開始」。

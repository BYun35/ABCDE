# 小星｜第一關網頁與機關驗收

依據小安 A 分支的 [content/BRIEF.md](https://github.com/BYun35/ABCDE/blob/A/content/BRIEF.md)。本檔只記錄小星負責的驗收條件，不修改或取代小安的劇情檔。

## 病房機關

- [ ] 玩家能查看三瓶藥物標籤、病歷碎片、日曆和牆上塗鴉。
- [ ] 玩家依病歷記載的服藥時間排列藥瓶，能推得密碼 `317`。
- [ ] 在電子鎖輸入 `317` 後，病房門開啟。
- [ ] 輸入錯誤密碼時，門不會開啟，畫面會給出清楚回饋。
- [ ] 玩家能找到藏有門禁卡的瓶罐，並取得卡片。
- [ ] 病歷碎片可以查看或拼合，玩家能讀到第 02 號病人完成記憶清除的線索。
- [ ] 主要操作可用滑鼠及觸控完成，手機與電腦畫面皆可閱讀和操作。

## 待小安補充後才能驗收

- 藥瓶標籤、服藥時間及正確排列順序。
- 日曆、塗鴉和病歷碎片各自提供的線索。
- 門禁卡藏在哪個瓶罐，以及取得後如何使用。
- 錯誤密碼是否可重試、是否保存進度。
